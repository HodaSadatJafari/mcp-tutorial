MCP stands for Model Context Protocol.

MCP is an open protocol for connecting AI applications
to external data sources, tools, and services.

An MCP server can expose tools, resources, and prompts.

Tools allow an AI application to perform actions.

Resources provide data or context that an AI application
can read.

MCP makes it possible for AI applications to interact
with external capabilities through a standardized protocol.


MCP ARCHITECTURE

An MCP system commonly contains a host, client, and server.

The host is the AI application that the user interacts with.

The MCP client maintains a connection with an MCP server.

The MCP server exposes capabilities such as tools, resources,
and prompts.

A single AI application can connect to multiple MCP servers.


MCP TOOLS

Tools are executable capabilities.

For example, an MCP server could expose a tool for searching
a database.

Another tool could create a support ticket.

Another tool could retrieve information from an API.


MCP RESOURCES

Resources represent data that an AI application can read.

Examples include files, database records, API responses,
documents, and other sources of context.

Resources are identified using URIs.


MCP AND AI AGENTS

MCP is useful for agentic AI systems because an agent can
interact with external capabilities through a standardized
interface.

Instead of implementing a custom integration for every
application, an AI application can communicate with MCP
servers using the MCP protocol.
